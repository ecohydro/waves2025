# Interface contract

Visitors reach useful research when the project catalogue is empty or temporarily unavailable.

- Distinguish a failed request from a successfully empty catalogue.
- Do not show total/active/featured zero counters as evidence of lab activity.
- Offer research and publication links for empty and failed collections.
- Preserve project detail routes, status labels, and existing records without fabricating projects.

Existing URLs remain valid. Tests must exercise the public rendered behavior, including errors and empty states, rather than only checking implementation text.
